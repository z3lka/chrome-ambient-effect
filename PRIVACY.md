# Privacy Policy for Ambient Focus for YouTube™

Last updated: October 2, 2026

Ambient Focus for YouTube™ is designed to work entirely in the browser. It
does not operate a server and does not retain, sell, or transmit user data. It
transiently processes the website content described below on the user's device.

## Data handled locally

On `https://www.youtube.com`, the extension reads the page structure and the
current video's frames to provide its visible features. Each frame is reduced
to a low-resolution canvas inside the open page and used only to draw the
ambient background. The extension does not retain those frames after display.

The extension does not access or store account details, form entries, cookies,
authentication data, browsing history, or personal communications. It contains
no analytics, advertising, tracking, or telemetry.

## Sharing and retention

No user data is sent to the developer or any third party. Because the extension
does not store user data, there is no retained user data to access, change, or
delete. Removing the extension removes its code from Chrome.

## Permissions

Site access is limited to `https://www.youtube.com/*`. This access is required
to add the player controls, adjust the watch-page layout, and render the local
ambient background. The extension does not execute remotely hosted code.

## Limited Use disclosure

Access to website content is used only to provide and improve the extension's
single user-facing purpose. It is not used or transferred for advertising,
profiling, creditworthiness, or any unrelated purpose, and humans do not read
the processed content.

## Changes and contact

Material changes to this policy will be published in this file with an updated
date. Questions or privacy concerns can be submitted through the project's
